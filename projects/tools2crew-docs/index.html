设备台账与课题接入文档体系（tools2crew）

进行时 · 把全部硬件说明书、局域网 HPC 服务器接入说明与课题交接文档整理成可检索的文件树与校验过的台账。

项目概述

进行时项目。 随着手、臂、传感与算力设备增多，说明书散落在不同机器的下载目录里，”要用的时候找不到”变成真实成本。本项目把这些资料收拢成一棵可检索的文件树，并对每份文档做来源与完整性标注。

目录结构

  • 硬件台账-说明书/01…07：按设备类别归档的说明书与规格书。
  • 接入与环境/：局域网 HPC 服务器接入说明、运行环境配置。
  • 00_课题交接/：课题交接、任务说明与当前状态。

核心工作

  • 文档收拢：逐台设备搜集说明书，统一命名与目录归属，剔除重复版本。
  • 完整性校验：对复制入库的文档计算 SHA-256，确认与来源一致。
  • 缺口标注：明确记录尚未取得说明书的设备，而不是留下”看起来齐了”的假象。
  • HPC 接入说明：把登录节点、GPU 队列、Slurm 提交与端口转发整理成可照做的步骤，附常见故障（代理干扰、作业被同名提交取消等）的排查顺序。

方法

文档体系的验收标准不是”文件存在”，而是”新人照文档能独立完成一次接入”。因此每份接入说明都要求写清前置条件、验证命令与失败判据。
